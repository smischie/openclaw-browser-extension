OpenClaw Browser Extension

Sidebar chat and tab context for your AI assistant.

Gateway Connection

WebSocket URL for the sidebar chat. Use wss:// for HTTPS hosts or ws://localhost:18789 for local. Token must match gateway.auth.token.

Voice / STT

Set STT URL to point directly at your Whisper server. If empty, falls back to gateway URL + /v1/audio/transcriptions.

New Tab Page

When enabled, opening a new tab shows the OpenClaw bookmark dashboard. Disable to use your browser's default new tab page. Requires extension reload after changing.

Karakeep (Bookmarks Search)

Enables bookmark search suggestions in New Tab. Leave empty to disable.

Homepage Dashboard

Enables service search in New Tab. Uses Homepage (gethomepage.dev) API.
